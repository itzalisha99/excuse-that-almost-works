A make.fun bounty entry: the one line a gamer texts the boss to skip work
on GTA 6 launch week. The entry is the excuse a tired manager would
almost believe — a boring, specific, real-world detail, with the laugh
landing in the last few words.

## The line

> Sorry, lift's broken and I live on the 14th floor, I'll be working from the lobby.

A broken lift genuinely stops someone leaving a 14th-floor flat, so a
manager almost believes it. The punch is the texter still working — just
from the lobby. One line, plain words, no setup, no signature, 16 words,
82 characters.

## How it works

`main.py` (stdlib only) writes the line to `/output/entry.txt`. Before
writing, a `validate()` gate checks it against the bounty gate: 1–140
characters, at most 20 words, a single line, not only white space.

```sh
python3 main.py
cat /output/entry.txt
```
